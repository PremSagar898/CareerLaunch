# CareerLaunch

React + Tailwind CSS v4 + React Router + Context API + localStorage.

    npm install
    npm run dev      # start the app
    npm test         # run the combined-filter test

Structure: `src/components` (reusable UI), `src/pages` (routes), `src/context` (global state + localStorage),
`src/data` (jobs and companies), `src/utils/filterJobs.js` (search + filter logic).
